# Marco — Calendario editorial 90 días

## Objetivo

Mantener **activas** Facebook, Instagram, WhatsApp Status y TikTok de Terra Natura con piezas **profesionales**, sin depender de inspiración diaria del dueño.

## Horizonte y ritmo

| Parámetro | Valor |
|-----------|--------|
| Días planificados | 90 |
| Publicaciones / semana | 7 (1 por día, rotando red) |
| Total aproximado | ~90 piezas en el trimestre |

## Mix de contenido (objetivos)

| Objetivo | % | Para qué |
|----------|---|----------|
| **cta_reserva** | 35 % | Llenar calendario PMS — puentes, verano, invierno |
| **fidelizacion** | 25 % | Huéspedes que vuelven, reseñas, comunidad |
| **utilidad** | 25 % | Tips Punilla/Bialet — guardados y shares |
| **branding** | 15 % | Estética complejo, confianza, “dueños en el predio” |

En **fines de semana largo** y **feriados**, el planificador **prioriza CTA** aunque el slot base sea otro objetivo.

## Rotación semanal (plantilla)

| Día | Canal | Formato | Base |
|-----|-------|---------|------|
| Lun | Instagram | Reel | Utilidad |
| Mar | TikTok | Reel | Branding |
| Mié | Facebook | Post | CTA |
| Jue | WhatsApp Status | Status | Fidelización |
| Vie | Instagram | Carrusel | CTA |
| Sáb | TikTok | Reel | Utilidad |
| Dom | Facebook | Post | Fidelización |

Horarios sugeridos: IG 10:00 · FB 12:00 · WA 18:00 · TikTok 20:00 (ajustar según insights).

## Flujo de trabajo

```
Feriados/puentes/vacaciones JSON
        ↓
calendar_90_planner → copy + guion + assets
        ↓
publicaciones_calendario.json (borrador)
        ↓
Dueño aprueba en /marketing
        ↓
Producir video (MoviePy / Canva) → publicar manual
        ↓
(V2) publicador_meta / TikTok API
```

## Cada publicación debe incluir

1. **Fecha y hora**
2. **Canal y formato** (reel, carousel, post, status)
3. **Objetivo** (cta_reserva, fidelizacion, utilidad, branding)
4. **Copy** listo para pegar
5. **Guion** (escenas, voz off, música, checklist)
6. **Assets** (rutas fotos locales + opcional clip YouTube)
7. **Brief Canva** si no hay video automático

## Integración con otros módulos

- **Turismo / YouTube:** clips para reels de entorno y eventos (`/api/turismo/youtube/recolectar`)
- **Grilla eventos:** Cosquín, ferias — reforzar copy en fechas cercanas
- **Channel manager:** si unidad vendida en OTA, pausar CTA de esa unidad (coherencia stock)
- **CRM:** leads de consultas alimentan ángulo “reserva directa”

## KPIs trimestrales (revisar mensual)

- Consultas WhatsApp atribuibles a post (preguntar “¿cómo nos conociste?”)
- Guardados / compartidos en reels de utilidad
- Reservas directas vs OTA en fechas de puente
- Tiempo dueño: &lt; 30 min/día aprobar y publicar con calendario lleno
