# Referencias GitHub — prompts y skills de marketing

Repositorios útiles para Terra Natura (turismo, IG, copy). **No commitear** clones grandes si el dueño prefiere solo este índice — clonar local con:

```powershell
cd "marketing/referencias/github"
git clone --depth 1 https://github.com/krishna-build/marketing-prompts.git
git clone --depth 1 https://github.com/SabrinaRamonov/prompts.git
git clone --depth 1 https://github.com/eigent-ai/agent-skills.git
```
