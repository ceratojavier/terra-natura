# Referencias de reels (Instagram / TikTok)

1. Guardá el reel en el celular (botón Guardar) o grabá pantalla **solo para estudiar**.
2. Pasá el archivo a `videos/` con nombre claro: `ref_cabana_carlos_paz_01.mp4`
3. Ejecutá `local/Analizar-referencia-reel.bat`
4. Opcional: editá la ficha en `indice.json` (gancho, notas).

**No subas estos MP4 a redes** — son solo para copiar la *forma* de editar.
