# Skill — Copy Terra Natura

## Antes de escribir

1. Leer `docs/COPY_TONO_MARCA.md`
2. Si existe: `marketing/contexto/00_voz_marca.md`

## Reglas obligatorias

- **Prohibido en copy público:** Punilla, Valle de Punilla, #ValleDePunilla
- **Usar:** escapada a las sierras, sierras de Córdoba, Bialet Massé, lago San Roque, refugio, reserva directa
- Español rioplatense, vos, cordobés suave
- CTA WhatsApp cuando corresponda venta/consulta
- No inventar fechas de eventos sin fuente confirmada

## Salida

- Título + cuerpo + hashtags (lista del doc de marca)
- Variante corta para WhatsApp si piden
- Si detectás "Punilla" en borrador previo, reescribir automáticamente

## Plantillas código

Alinear con `ama/templates/copy_prompts.yaml` tras cambios de vocabulario.
